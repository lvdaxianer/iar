# Design

## Context

最新 master 的沙箱事件日志已有动作结果，压缩服务验证候选状态、引用和关键哈希，但服务只有一个共享会话。语义调用只传本轮文本，兜底回复和压缩调用还传递最近对话原文。现有 JEV 与意图模型共享决策结果契约，不应被本变更破坏。

## Goals / Non-Goals

**Goals:** 隔离每个会话，以作用域内的可信事件实时构造通用结构化事实，复用成功压缩结果，让模型根据本轮问题与上下文理解追问，并覆盖流式及非流式路径。

**Non-Goals:** 不新增真实工单管理后端，不改变其他插件的授权与执行策略，也不将模型摘要当作业务事实源。

## Decisions

1. 服务以不可猜测的会话标识隔离事件、投影、事实、摘要和待确认动作，同一会话请求串行化；提供已有客户端的兼容路径、过期清理和受控资源上限。沙箱标识并不替代生产身份认证和租户授权。
2. 每次事件成功追加后实时更新会话视图：行为状态由投影器维护，操作事实从同一会话成功事件和功能公开输出契约中提取，携带来源事件、状态及有界字段。未知或未声明可公开字段的功能不复制任意输出。已截断或不可验证的数据不能作为完整事实。
3. 每轮模型请求分别传当前输入与当前结构化视图；语义、普通回复、流式回复和兜底均复用同一轮一致快照，不传历史消息原文。将事实内容当作不可信数据，不能改变系统指令或授权策略。
4. 模型依据问题和上下文区分回答、选择功能与澄清；无可靠功能选择或语义不确定时使用基于事实的模型兜底。缺少明确新操作意图时不得因关键词或默认 operation 触发副作用；对复合、不确定请求澄清。不得为工单或任何单一业务建立硬编码追问路由。
5. 压缩模型接收结构化状态及事件，不传最近消息原文；只使用已校验的压缩结果作为辅助摘要，关键事实从可信事件维护。压缩失败保留旧视图，预算边界可追溯且不跳过未压缩事件。
6. JEV 优先级、有限候选、共享决策返回契约和最终授权、策略、确认边界维持不变；根据角色仅传递适用的上下文，不能扩充 JEV 私有返回契约。
7. 对既有会话与模型提供器按职责拆分，保留十子系统及公开接口、事件顺序、错误语义和确认行为；安全合并旧工作树的未完成改动，不覆盖最新 master。
8. 沙箱入口和模型调用共用受控结构化日志，显式传播链路标识；外部请求正常时 DEBUG、失败及慢请求 WARN。仅记录固定白名单元数据，默认不记录正文、请求头、凭据或原始异常；运行中可受控切换调试级别。流式调用覆盖读取结束及中断。
9. 每个会话的结构化视图一经更新即将不可变、有版本的完整快照排入异步 SQLite 写入队列；快照包括可信事实、来源、行为状态及已校验的摘要。同会话写入有序，并用版本比较阻止旧版本覆盖新版本。SQLite 同步驱动在独立工作线程执行，避免阻塞会话处理；对队列容量、失败重试、持久化错误以及关闭时等待队列排空设置有界策略。异步排队不保证进程突然终止前的数据已落盘，不能对用户声称同步持久化。
10. 使用原会话标识恢复最新成功写入的有效版本后再处理该会话的新问题；恢复与写入遵守隔离和同会话顺序，损坏或不兼容快照不得作为可信事实使用，失败要可观察并保持安全。沙箱通过 `POST /api/sessions/{sessionId}/resume` 显式恢复，避免把“快照存在”误当成当前内存会话已经创建；恢复完成前该会话不接受新操作。会话标识仅用于沙箱隔离，不代替身份验证与租户授权。`IAR_SANDBOX_SQLITE_PATH` 或 `startSandboxServer({ snapshotPath })` 明确数据库路径，未配置时使用进程内 SQLite；正常关闭排空已接受写入，异常退出窗口内的更新不作持久化承诺，测试使用隔离临时库。

## Risks / Trade-offs

- [事实过期或跨会话泄漏] → 按会话事件来源和顺序构建，限制字段并保留来源事件。
- [摘要丢失编号或幻觉] → 编号只来自可信成功事件；摘要仅用于辅助理解。
- [语义不明确触发副作用] → 查询与创建明确区分，不确定时澄清。
- [上下文增长] → 设定可预测大小边界，保留必要事实与可用的最近压缩快照。
- [拆分引入回归] → 保持公开入口与现有契约，运行全套集成测试并针对大小限制增加自动检查。
- [日志泄露或放大] → 不信任自由文本、URL 查询或异常内容；按白名单记录有界安全字段，验证调试关闭和流式异常场景。
- [上下文包含敏感内容或注入指令] → 用输出契约、权限与敏感字段策略过滤并限制长度；将其作为数据而非指令，白名单本身不保证自由文本已脱敏。
- [多个客户端共享沙箱] → 会话标识隔离、同会话顺序化，生产接入必须另行落实身份和租户授权。
- [异步落盘丢失或写入乱序] → 顺序版本校验、失败告警与有界重试、正常关闭时排空；异常退出期间未提交更新可能丢失。
- [重启后恢复内容不完整或不可信] → 快照覆盖全部结构化视图、校验版本和字段；无效数据不作为事实使用。

## Migration Plan

保留现有事件契约与决策输出，增量引入可选模型上下文；如需回滚，移除上下文视图接入即可，不修改既有事件日志。
