# Proposal

## Why

真实模型驱动的 Agent Sandbox 刁钻场景测试发现，已验证的动作目标在
增量参数追问中可能丢失，导致输入被错误交给 Pi 兜底，无法形成新的待确认动作。
现有 24 场景回归没有覆盖这类中文增量、百分比和单会话连续输入的组合。

## What Changes

- 将“继续上调/下调 N”识别为当前已验证目标上的参数变更，并重新进入参数校验、策略和确认流程。
- 保持单会话连续输入时，当前轮明确的增量参数优先于旧动作结果，不把新输入交给无关的 Pi 兜底。
- 增加场景 4 的回归测试，并使用 8878 真实模型重新执行 50 个场景；测试驱动器会显式处理清单中隐含的确认步骤。
- 对真实模型测试中发现的其他可复现上下文、确认和安全缺陷按同一变更继续补充回归与修复。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `continuation-recovery`: 增量参数续问必须恢复已验证目标并重新进入安全执行流程。
- `structured-model-context`: 单会话连续输入中的当前轮参数和历史事实必须保持边界，不能因上下文累积而丢失当前操作。

## Impact

影响 `examples/agent-sandbox` 的语义抽取、续问恢复和路由回退逻辑，以及对应集成测试。
不新增外部 API，不改变插件副作用模型；真实测试仍只使用 sandbox 的确定性 fixture。
