# Phase 4 Task 4.4 Observability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立统一的 trace、metric、structured-log、audit 记录边界和 system logging plugin，默认脱敏敏感字段，并证明 observer 故障不阻断业务事件。

**Architecture:** 新建 `@iar/observability` 作为唯一观测写入边界：所有记录共享版本、trace/run/event 关联字段，先做字段白名单与递归脱敏，再写入可注入 sink 和本地快照。新建 `@iar/built-in-plugins` 提供 `iar.observability.log` system plugin、fail-open 异步订阅和允许的生命周期/业务摘要字段；它不把原始 event payload、prompt 或用户输入写入日志，也不进入业务路由候选。

**Tech Stack:** TypeScript NodeNext、`@iar/contracts` JSON boundary、`@iar/subscriptions` `SubscriptionDispatcher`/`SubscriptionRegistry`、Node test runner；不引入真实 OpenTelemetry/Pino runtime，sink 接口为后续适配保留确定性边界。

- [ ] **Step 3: Add the versioned record types**

In `types.ts`, define the exact public shapes:

```ts
export const OBSERVABILITY_SCHEMA_VERSION = 'iar.observability/v1' as const;
export type ObservabilityKind = 'log' | 'trace' | 'metric' | 'audit';
export type LogLevel = 'trace' | 'debug' | 'info' | 'warn' | 'error';
export type ObservabilityFields = {
  route?: string; tenantId?: string; functionId?: string; pluginId?: string;
  pluginVersion?: string; durationMs?: number; resultCode?: string;
  errorClass?: string; policyDecision?: string; confirmationState?: string;
  [key: string]: JsonValue | undefined;
};
export type ObservabilityRecord = {
  schemaVersion: typeof OBSERVABILITY_SCHEMA_VERSION; kind: ObservabilityKind;
  timestamp: string; traceId: string; runId: string; eventName: string;
  fields: Record<string, JsonValue>; level?: LogLevel; name?: string; value?: number;
};
export type ObserverSink = { write(record: ObservabilityRecord): void | Promise<void> };
export type ObservabilityOptions = { sink?: ObserverSink; clock?: () => string; sensitivePaths?: readonly string[]; maxMetadataBytes?: number };
```

Import `JsonValue` from `@iar/contracts`; keep every public record JSON-safe and correlated by required `traceId`, `runId`, and `eventName`.

- [ ] **Step 4: Implement redaction before emission**

`redaction.ts` must recursively clone plain JSON objects and arrays, replace values whose key or configured dotted path matches `apiKey`, `authorization`, `rawPrompt`, `rawUserInput`, `password`, `token`, `secret`, `credential`, `cookie`, or `privateKey` with `[REDACTED]`, and reject cycles/non-JSON values with `[UNSAFE_REDACTED]`. It must never mutate the caller’s object and must apply configured `sensitivePaths` in addition to the defaults.

- [ ] **Step 5: Implement the recorder and fail-open sink boundary**

`ObservabilityRecorder` exposes `log`, `trace`, `metric`, `audit`, `snapshot`, and `observerFailureCount`. Each method builds the versioned record, redacts fields, enforces `maxMetadataBytes`, stores only the sanitized snapshot, and calls the injected sink. A sink throw/rejection increments `observerFailureCount` and records a sanitized correlated `observability.observer_failed` audit/metric snapshot without rethrowing; no raw exception message or original payload is emitted.

test('system logging plugin is runtime-scoped, fail-open and excludes raw payload', async () => {
  const recorder = new ObservabilityRecorder({ sink: { write: async () => { throw new Error('sink unavailable'); } } });
  const plugin = createSystemLoggingPlugin(recorder);
  assert.equal(validatePluginManifest(plugin.manifest).ok, true);
  assert.equal(plugin.manifest.pluginKind, 'system');
  assert.equal(plugin.subscription.failurePolicy, 'fail-open');
  const result = await plugin.handler({ eventId: 'event-1', eventName: 'input.received', runId: 'run-1', correlationId: 'trace-1', payload: { rawPrompt: 'prompt', rawUserInput: 'input', apiKey: 'key', route: '/v1/runs' } }, plugin.subscription, new AbortController().signal);
  assert.equal(result.patch, undefined);
  assert.equal(recorder.observerFailureCount, 1);
  assert.equal(JSON.stringify(recorder.snapshot()).includes('prompt'), false);
});

It must never pass the full event payload. It returns `{}` and does not deny, patch, or alter the business action.
