# Phase 4 Task 4.3 Isolated Executors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Worker、Sidecar、container 三种执行模式建立统一的能力范围、超时/取消、资源限制、凭据隔离、版本固定和清理契约，并证明插件超时或卸载后不会保留 active subscription。

**Architecture:** 新建 `@iar/adapters-executors`，以版本化 JSON-safe `ExecutorRequest/ExecutorResponse` 作为唯一边界。Worker、Sidecar、container 先共享一个受限执行核心：校验 tenant/plugin/version/capabilities，使用 AbortController 和资源预算包裹 Handler，凭据只能通过按 tenant/plugin/version 绑定的 resolver 获取，cleanup 同时取消活动请求并注销插件订阅；三种 adapter 只负责声明模式和生命周期，不复制 PluginHost 或 SubscriptionRegistry 语义。

**Tech Stack:** TypeScript NodeNext、Node `AbortController`/`setTimeout`、`@iar/contracts` JSON 校验、`@iar/plugin-sdk` Handler、`@iar/subscriptions` SubscriptionRegistry、Node test runner。

```ts
test('worker times out and cancellation prevents a late handler result', async () => {
  const executor = createWorkerExecutor({ version: '1.0.0', maxTimeoutMs: 100 });
  const pending = executor.execute(validRequest({ timeoutMs: 10 }), async (_input, _context, signal) => {
    await new Promise<void>((resolve) => setTimeout(resolve, 50));
    assert.equal(signal.aborted, true);
    return { output: { late: true }, status: 'succeeded' };
  });
  const response = await pending;
  assert.equal(response.error?.code, 'executor.timeout');
  assert.equal(response.data, null);
  await executor.close();
});

test('worker resolves credentials only inside tenant/plugin/version scope', async () => {
  const seen: string[] = [];
  const executor = createWorkerExecutor({ version: '1.0.0', maxTimeoutMs: 100, resolveCredential: (scope, ref) => {
    seen.push(`${scope.tenantId}:${scope.pluginId}:${scope.pluginVersion}:${ref}`);
    return 'secret-value';
  }});
  const response = await executor.execute(validRequest({ credentialRefs: ['api-key'] }), async () => ({ output: { ok: true }, status: 'succeeded' }));
  assert.equal(response.error, null);
  assert.deepEqual(seen, ['tenant-a:plugin-a:1.0.0:api-key']);
  await executor.close();
});
```

- [ ] **Step 3: Implement the shared constrained core**

`core.ts` must perform, in order: validate request; pin `pluginVersion` against adapter version; verify every requested capability against an exact allow-list; resolve only declared credential refs through a scoped resolver without putting values into request/response; create an `AbortController`; enforce `min(request.timeoutMs, maxTimeoutMs)`; enforce a bounded `maxInputBytes` and `maxOutputBytes`; clone/validate handler result; convert handler throws to `executor.handler_failed`; map abort to `executor.cancelled` or `executor.timeout`; and remove the request from the active map in `finally`.

- [ ] **Step 4: Implement Worker mode as a thin adapter**

`worker.ts` must expose `createWorkerExecutor(options)` and use the shared core with `mode: 'worker'`. `cancel(requestId)` calls `AbortController.abort()` and returns false for unknown IDs. `close()` cancels every active request and waits for all cleanup promises. No Worker adapter may mutate PluginHost or SubscriptionRegistry directly.

```ts
function pluginSubscription(pluginId: string): HookSubscription {
  return { subscriptionId: `${pluginId}.subscription`, event: 'plugin.enabled', handler: { type: 'plugin', ref: `${pluginId}.handler` }, delivery: 'async', priority: 0, failurePolicy: 'fail-open' };
}

test('timeout and plugin unload leave no active request or subscription', async () => {
  const registry = new SubscriptionRegistry();
  registry.register(pluginSubscription('plugin-a'));
  const executor = createWorkerExecutor({ version: '1.0.0', maxTimeoutMs: 100, subscriptionRegistry: registry });
  await executor.execute(validRequest({ timeoutMs: 5 }), async () => new Promise(() => undefined));
  assert.equal(executor.activeRequestCount(), 0);
  await executor.cleanupPlugin('tenant-a', 'plugin-a');
  assert.equal(registry.get('plugin-a.subscription'), undefined);
  await executor.close();
});
```
