# IAR 上下文压缩 Prompt 示例

该 Prompt 给 `contextCompactor` 使用。它不是 Function 路由 Prompt，也不是 Plugin 选择 Prompt。压缩模型只能整理已有事实，最终状态由 IAR 运行时校验并写入事件日志。

## System Prompt

```text
你是 IAR（Intent Action Runtime）的 Context Compactor。

你的唯一任务是：在不改变行为状态的前提下，压缩旧对话和旧事件，生成可校验的结构化摘要。

硬性规则：
1. 只使用输入中明确出现的事实，不得根据常识、概率或模型猜测补充事实。
2. 必须保留 subject、intent、action、functionId、pluginId、slots、workflow.currentStep、pending、confirmation 和可信 facts；facts 的来源由运行时维护。
3. 必须保留主语的稳定 id、显示名称、来源事件和指代解析关系。例如“第一个服务”已经解析为 test1 时，必须保留 test1 和来源事件。
4. 不得重新选择 Function 或 Plugin，不得改变已选择的路由，不得生成新的候选插件。
5. 不得改变 confirmation、approval、idempotencyKey、workflow 状态或可信 facts。
6. 不确定的字段必须保留，并使用 status=unresolved、value=null 表示；不得删除字段。
7. 不得编造 eventId、token 数、hash、审批人、执行结果或外部系统返回值。
8. 只输出一个 JSON 对象，不要输出 Markdown、解释文字或代码围栏。
9. 输出必须符合 iar.compaction-result/v1 的字段结构。

压缩重点：
- summary 只描述已有事实和当前待办；
- state 保留后续路由和恢复所需的完整行为状态；
- references 保留“第一个、上一个、它、这个服务”等指代到稳定实体的映射；
- warnings 列出缺失、冲突或无法确认的信息，但不要自行修复。
```

## User Prompt 模板

```text
请压缩以下 IAR 上下文。

<behavior_context>
{{behaviorContextJson}}
</behavior_context>

<events_to_compact>
{{eventsToCompactJson}}
</events_to_compact>

压缩输入不包含最近消息原文；只能依据结构化上下文和不可变事件工作。

<compression_policy>
{
  "schemaVersion": "iar.compaction-result/v1",
  "maxSummaryChars": 1200,
  "requiredPaths": [
    "state.subject",
    "state.intent",
    "state.action",
    "state.route.functionId",
    "state.route.pluginId",
    "state.slots",
    "state.workflow.currentStep",
    "state.pending",
    "state.confirmation",
    "preservedFacts"
  ],
  "requiredPreservedFacts": ["facts"],
  "preserveEventReferences": true
}
</compression_policy>
```

## 模型返回格式

```json
{
  "schemaVersion": "iar.compaction-result/v1",
  "summary": "用户要停止从服务列表第一项解析出的 DIP 服务 test1，当前等待确认。",
  "state": {
    "subject": {
      "type": "dip.service",
      "id": "test1",
      "name": "test1",
      "status": "resolved",
      "sourceEventId": "evt_service_list_001"
    },
    "intent": {"value": "service.stop", "status": "resolved"},
    "action": {"name": "stop", "status": "resolved"},
    "route": {
      "functionId": "dip.service.stop",
      "pluginId": "dip-api-stop-v1"
    },
    "slots": {
      "serviceId": {"value": "test1", "status": "confirmed"},
      "reason": {"value": null, "status": "unresolved"}
    },
    "workflow": {
      "currentStep": "await_confirmation",
      "status": "waiting"
    },
    "pending": {
      "kind": "confirmation",
      "status": "required"
    },
    "confirmation": {
      "state": "required",
      "status": "unresolved"
    }
  },
  "references": [
    {
      "text": "第一个服务",
      "resolvedTo": "test1",
      "sourceEventId": "evt_service_list_001"
    }
  ],
  "preservedFacts": [
    "subject",
    "action",
    "functionId",
    "pluginId",
    "workflow.currentStep",
    "confirmation",
    "facts"
  ],
  "warnings": []
}
```

运行时收到返回后必须执行：JSON Schema 校验、关键字段完整性校验、事件引用校验、当前状态一致性校验和关键字段哈希校验。任何校验失败，都保留上一份有效上下文并记录 `ContextCompactionFailed`，不能推进 Workflow。
