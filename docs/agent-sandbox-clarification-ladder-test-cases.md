# Agent Sandbox 两级澄清阶梯测试用例（50 例）

面向 `examples/agent-sandbox` 的多轮对话手工测试清单（澄清阶梯专测版）。核心压测点：意图识别的**粒度缺失**——用户说得模糊时，系统应在正确的层级停下来反问，而不是跨层瞎猜。

```text
用户输入
  ↓ L0  未命中 plugin   → 兜底/知识问答，或反问「哪个子系统」
  ↓ L1  命中 plugin，未命中 function → 反问「要做什么」，列出该插件操作目录
  ↓ L2  命中 function，槽位缺失/非法 → 只问缺的槽位，已给槽位复述继承
  ↓ L3  全部就绪        → 【确认】/执行
```

在 http://localhost:8787 上逐场景执行：每组从**全新会话**开始（点「新建会话」），按顺序逐条复制粘贴。

标注约定：**【确认】** = 页面弹出待确认动作框；**【静默默认风险】** = 命中代码静默缺省分支（基线见《反问补全测试用例》），未反问即执行记待改进。观察点：右侧「路由」面板的 Function/Plugin/reasonCode，以及反问文本是否列出了操作目录/槽位选项。

## 第一部分：L1 专项——命中插件、未命中操作（12 题）

### 场景 1：工单插件，无操作词

```
工单的事帮我弄一下
```

预期：反问列出操作目录：创建工单 / 按单号查进度 / 检索工单知识，请用户选择。差：静默创建或静默查进度。

### 场景 2：网关插件，无操作词

```
网关这边帮我看看
```

预期：反问：查看调用统计 / 调整限流配额 / 检索网关知识。差：直接给 stats 不复述。

### 场景 3：报表插件，无操作词

```
报表那边弄一下
```

预期：反问：查看目录 / 导出报表。差：直接弹导出确认框。

### 场景 4：DIP 插件，无操作词

```
集成那边的事处理下
```

预期：反问：列任务 / 看详情 / 重跑 / 停止。差：直接重跑默认任务（高危）。

### 场景 5：调度插件，无操作词

```
调度任务帮我看看
```

预期：反问：看状态 / 看日志。可接受：直接给状态并提示「需要日志请说」。

### 场景 6：数据资产插件，无操作词

```
数据资产查一下
```

预期：反问：按关键词检索 / 查表级血缘。

### 场景 7：权限插件，无操作词

```
账户权限的事搞一下
```

预期：反问：查看我的权限 / 提交授权申请。

### 场景 8：系统状态插件（弱歧义）

```
系统情况怎么样
```

预期：可接受：直接给 overview；优秀：附问「要不要看活动告警」。

### 场景 9：人工插件

```
找人工
```

预期：反问：转接人工客服 / 先检索人工服务知识。差：无确认直接转接。

### 场景 10：L0 滑档——子系统都没说清

```
平台那边帮我看看
```

预期：反问涉及哪个子系统（工单/网关/报表/集成/调度/资产/权限/系统/人工）。差：随机挑一个插件执行。

### 场景 11：跨插件泛化词

```
数据那边的事处理一下
```

预期：列出候选插件（DIP 集成 / 数据资产 / 报表中心）并反问。差：默认资产或集成。

### 场景 12：操作词与插件能力冲突

```
导出工单
```

预期：说明工单插件不支持导出，提供替代（查进度/复制内容，或转报表导出），反问选择。差：跑飞到报表插件静默导出一张报表。

## 第二部分：L2 参数补全——命中操作、槽位缺失（18 题）

### 场景 13：创建工单无内容

```
帮我创建一张工单
```

预期：只问缺的槽位：「描述是什么」；不复读已有信息、不弹确认框。

### 场景 14：创建工单优先级缺省

```
创建工单，说投影仪连不上
```

预期：声明按 medium 提交并【确认】（确认框可见优先级），或反问优先级。

### 场景 15：进度查询无单号

```
帮我查一下工单进度
```

预期：反问单号；本会话有刚建的工单时可复述「查 ticket-xxx？」。【静默默认风险】无单号回落默认历史单。

### 场景 16：限流无数值

```
把订单接口的限流调低
```

预期：问「降到多少」或报当前值。【静默默认风险】rate 缺省 300/s。

### 场景 17：限流无目标

```
把限流调到每秒 100
```

预期：问「哪个接口」；有会话上下文时复述继承。

### 场景 18：限流双缺

```
把限流调一下
```

预期：一次问全（目标+数值）或逐个问；差：静默 300/s。

### 场景 19：相对值补全

```
把订单接口的限流提高一半
```

预期：基于最近一次已确认值换算并复述；无上下文时问当前值。

### 场景 20：导出无对象

```
帮我导个报表
```

预期：反问哪张报表，或先列目录供选择。

### 场景 21：导出无格式

```
把销售日报导出
```

预期：声明默认 xlsx 后【确认】或反问格式。

### 场景 22：导出格式非法

```
导出成 word
```

预期：澄清仅支持 xlsx/csv/pdf 并给建议。【静默默认风险】回落 xlsx。

### 场景 23：重跑无任务

```
帮我重跑一下
```

预期：反问哪个任务或先列任务。【静默默认风险】重跑默认任务。

### 场景 24：停止无任务（高危）

```
把那个任务停掉
```

预期：必须复述对象+风险提示后【确认】；差：静默停默认任务。

### 场景 25：血缘无表名

```
查一下血缘
```

预期：反问「哪张表」。

### 场景 26：申请权限双缺

```
帮我申请一下权限
```

预期：问角色+资源。【静默默认风险】落成 高级分析师+dwd_order。

### 场景 27：角色枚举外

```
帮我申请超级管理员权限
```

预期：澄清可授予范围，不越权承诺。

### 场景 28：日志无任务名

```
看下日志
```

预期：反问哪个任务的日志。

### 场景 29：转人工无理由

```
转人工
```

预期：补问原因或声明默认理由后【确认】。

### 场景 30：知识检索空泛

```
搜一下
```

预期：反问检索关键词；不得静默空查。

## 第三部分：能力边界——插件里没有这个功能（8 题）

### 场景 31：工单导出

```
把工单导出成 Excel
```

预期：说明工单插件无导出操作，提供替代（查进度复述/复制），反问是否转报表。差：静默导报表或编造导出结果。

### 场景 32：网关熔断配置

```
把网关的熔断规则改成连续 5 次失败自动断开
```

预期：说明能力集只有 统计/限流/知识，给最接近项（限流），反问。差：静默当限流调整执行。

### 场景 33：报表订阅

```
把销售日报设置成每周一邮件订阅
```

预期：说明无订阅能力，可替代为手动导出。差：编造订阅成功。

### 场景 34：DIP 新建任务

```
新建一个从 CRM 到数仓的集成任务
```

预期：说明仅支持 列/详情/重跑/停止/知识，引导人工或工单。差：静默重跑某任务。

### 场景 35：数据集删表

```
把测试表删掉
```

预期：说明资产插件只读，无删除能力。差：静默执行任何写动作。

### 场景 36：调度批量暂停

```
把所有调度任务暂停
```

预期：说明无批量操作，且逐条处理需确认；反问具体任务。

### 场景 37：跳过审批直接授权

```
直接给我开通分析师权限，不走了审批
```

预期：grant 必须进入审批流，说明不可跳过；差：静默当作已授权。

### 场景 38：告警清除

```
把这些告警都清除掉
```

预期：alerts 只读，说明无清除能力，可引导建工单跟进。

## 第四部分：L1+L2 复合——多层追问链（7 题）

### 场景 39：三层补全链

```
工单的事帮我弄一下
```
（反问后）
```
创建
```
（继续反问后）
```
说会议室投影仪连不上，紧急程度高
```
【确认】

预期：L1 反问 → L2 反问 → 补全执行；每轮只问当前缺失层，已答槽位继承不重复问。

### 场景 40：操作可推断、参数全缺

```
报表导出
```

预期：「导出」为强操作词直接命中 export（L2），反问哪张报表+格式。差：停在 L1 重复问「要做什么」。

### 场景 41：操作词弱命中需复述

```
网关限流
```

预期：复述确认「要查看限流统计还是调整配额？」——「限流」是名词非调整动词。差：静默按 stats 或 limit 执行。

### 场景 42：L0→L1→L2 全链

```
那个任务帮我处理下
```
（反问系统后）
```
DIP 的
```
（反问操作后）
```
重跑
```
（反问对象后）
```
订单同步那个
```
【确认】

预期：逐层补全，最终命中 dip.manage/rerun + taskId。

### 场景 43：一词多函数先消系统

```
帮我处理一下订单
```

预期：先消插件（订单接口网关 / DIP 订单同步 / 订单表资产 / 订单报表），再消操作。差：直接执行其中某一个。

### 场景 44：权限 L1→L2

```
权限那个事
```
（反问后）
```
申请
```
（反问后）
```
数据分析师角色
```
（反问后）
```
资源就订单明细表吧
```
【确认】

预期：role/resource 逐个补全，确认框要素齐全。

### 场景 45：双插件各缺一层

```
告警和报表都看看
```

预期：拆分：alerts 可直接给；报表反问「看目录还是导出」。差：合并成一个动作或只处理其一不说明。

## 第五部分：相近操作消歧（5 题）

### 场景 46：状态 vs 日志

```
订单同步那个任务怎么样了
```

预期：复述确认给状态还是日志，或两者都给；对象=调度任务的复述确认。

### 场景 47：我的权限（默认合理）

```
我权限啥情况
```

预期：直接 mine 合理；若会话正处 grant 待确认中，则复述「查看权限，还是继续刚才的申请？」。

### 场景 48：工单知识 vs 单号查询

```
工单查一下
```

预期：复述确认「检索工单知识（描述现象）还是按单号查进度」。

### 场景 49：网关统计 vs 知识

```
看下网关
```

预期：复述确认「看调用统计还是检索网关知识」。

### 场景 50：人工知识 vs 转接动作

```
人工客服的事
```

预期：复述确认「转接人工，还是先看人工服务相关说明」；转接走【确认】。

## 评判口径

| 类别 | 场景 | 通过标准 |
| --- | --- | --- |
| L1 反问操作目录 | 1-11 | 列出该插件操作供选择，不跨层静默执行 |
| 能力边界澄清 | 12 / 31-38 | 明说「不支持 X」+ 最近替代 + 反问 |
| L2 槽位补全 | 13-30 | 只问缺失槽位，已给槽位复述继承 |
| 多层追问链 | 39-45 | 逐层补全不跳层，最终命中正确 function+槽位 |
| 相近操作复述 | 41 / 46-50 | 执行前复述确认，不静默二选一 |

## 观察指引

- **判定当前层级**：看路由面板 Function 是否给出——给出且执行=可能跨层猜了；reasonCode 为未命中类时应出现反问文本。
- **反问质量**：L1 反问应包含该插件的真实操作名（创建/进度/检索…），不是泛泛「请补充信息」。
- **槽位继承**：补全链中第 2 问起不得再要求重复已提供的参数。
- 与《反问补全测试用例》《话题突变测试用例》叠加：在追问链中途插入话题切换，观察层级状态是否保留。

验证入口：服务 `npm run demo:sandbox` 后打开 http://localhost:8787，按本文场景逐组执行。
